
# 🚀 JSCamp — Full-Stack JavaScript

Repositorio personal de aprendizaje y práctica del **Bootcamp JSCamp**, creado por [midudev](<https://midu.dev/>).

El objetivo de este repositorio es documentar mi progreso mientras aprendo **desarrollo Full-Stack con JavaScript**, incluyendo fundamentos de desarrollo web, frontend, backend, bases de datos, testing, TypeScript, IA, CI/CD y DevOps.

- Documentar mi proceso de aprendizaje.
